# 🏠 House Price Prediction

## 📌 Problem Statement
Predict the sale price of houses based on various features using regression models.

## 📂 Dataset
- Source: [Kaggle House Prices](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)
- Files: `data.csv'

## ⚙️ Approach
- Data cleaning and preprocessing
- Feature engineering
- Linear Regression model
- Evaluation using Mean Squared Error (MSE)

## 📊 Results
- MSE: 59764123653.59795
- Visualizations: Actual vs Predicted prices
